# 可替换分层角色模型

在角色上右键，打开「角色模型」：可选内置鲸鱼娘分层动态模型、经典三姿态立绘，或「加载其他分层模型…」。托盘菜单也有相同入口。选择其他模型时指向该模型文件夹内的 `model.json`；选择会保存在本机设置中。模型加载失败时会提示原因并保留当前选择。

## 当前支持的模型

程序使用自有的 `whale-layered-1` 二维分层格式。它把透明 PNG 部件按前后顺序组合，对头发、头部、手脚和身体施加独立运动，也能切换开眼／闭眼图。内置鲸鱼娘模型位于 `models/whale-rig/`，可以复制整个文件夹作为制作其他角色的起点。替换模型的图片只在本机读取，不会上传到聊天 API。

**这个格式不是 Live2D Cubism。** 不能直接加载 `.model3.json`、`.moc3` 或 `.motion3.json`。现有鲸鱼娘原始素材是完整 PNG；这次制作了可用的分层贴图和简单关节动作，但没有 Cubism Editor 的网格、参数绑定与 `.moc3` 导出文件。要制作真正的 Cubism 模型，需在官方编辑器中整理 PSD 图层、建立变形器和参数、绑定动作，再按官方流程导出模型。未来接入 Cubism 运行时还需满足其 SDK 和模型的许可条件。

本仓库另有 [Cubism 编辑器素材交接](Cubism编辑器交接.md)，可将这些部件导出成待绑定的 13 图层 PSD。

## 文件格式

把 `model.json` 与所有贴图放在同一个文件夹。内置模型的配置可以直接作示例。关键字段：

| 字段 | 含义 |
|---|---|
| `format` | 固定为 `whale-layered-1` |
| `name` | 菜单使用的名称，最长显示 40 个字符 |
| `layers` | 从后到前的部件数组，允许 3–48 层 |
| `id` | 部件的唯一名称 |
| `image` | 同文件夹内的 PNG 文件名，不允许子目录或上级路径 |
| `crop` | 源图上的 `[x, y, 宽, 高]`，单位为像素 |
| `frame` | 300×300 角色画布上的 `[x, y, 宽, 高]` |
| `channel` | 动作通道，见下表 |
| `fadeLeft` | 可选，左边缘透明渐入比例，范围 0–0.5；仅用于修饰裁切接缝 |

| `channel` | 作用 |
|---|---|
| `back-hair`、`front-hair` | 跟随头部，稍慢回正 |
| `head` | 随头部轻转和点头 |
| `eye-open`、`eye-closed` | 眨眼时交替显示 |
| `torso`、`skirt` | 呼吸和身体微动 |
| `left-arm`、`right-arm` | 点击与待机动作 |
| `left-leg`、`right-leg` | 步态和重心微动 |
| `head-open`、`head-closed` | 可选的整头开／闭眼切换 |

所有贴图都应有真实透明背景。单张图片不得超过 16 MB 或 4096×4096 像素；模型配置不得超过 128 KB。部件会按 JSON 顺序覆盖绘制。外部模型暂按站姿驱动；若需要坐姿或趴姿，可切回内置模型或经典立绘。

## 制作建议

为每个关节留下被其他部件遮挡的绘画延伸部分。例如手臂在袖口处多画一点，转动时就不会露出空隙。头发与脸、眼睛与眼眶应在同一坐标系下对齐。角色默认尺寸是 300×300，再由程序整体缩放；建议先在 100% 比例检查接缝、眨眼、触碰动作和透明背景。

内置素材的生成记录见 `art-notes/分层模型生成提示词.txt`。以其他作品为参考时，请确认自己有权使用和分发贴图。
