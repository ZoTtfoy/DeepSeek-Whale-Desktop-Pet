# DeepSeek 小鲸鱼 · 自然动作版

## 开始使用

先在系统托盘退出旧版，完整解压新版，双击 **DeepSeekWhale.exe**。保留 `poses`、`models` 文件夹与 `.exe.config`。适用于 .NET Framework 4.8 的 Windows 10/11，无需安装 DSH、Python、Node.js。原来的 API Key、字号、位置等本机设置继续使用。

## 更换角色模型

右键角色或打开托盘菜单，选择「角色模型」即可切换内置鲸鱼娘分层动态模型、经典三姿态立绘，或选择另一个本地模型文件夹中的 `model.json`。新安装默认显示内置分层站姿；内置模型切到坐姿／趴姿时自动使用经典立绘。外部模型暂按站姿驱动。模型文件需要和贴图一起保存；移动或删除文件夹后，需要重新选择。

分层动态模型把面部、眼睛、刘海、身体与手脚作为独立贴图运动。眨眼会渐变，头发略晚于头部回正。它使用项目自己的 `whale-layered-1` 格式，**不是 Live2D Cubism 模型**，不能加载 `.model3.json` 或 `.moc3`。制作和替换步骤见 [分层模型格式](分层模型格式.md)。

## 这次动画改了什么

- 立绘由连续网格承载：头部轻转、呼吸、头发跟随和手脚的小动作分别计算。头发比头部晚一点回正，落地接触部位不随头部漂移。
- 点头部是轻轻摸头，身体点击轮换歪头、舒展、轻触和小跳。动作幅度更小，跳跃保留蓄力、重力方向与落地缓冲。
- 连续点击两三次害羞，四次以上轻轻抗议；保留对应台词。柔和动作可立即转换表情，运动速度延续，避免突然归零；跳跃中则等落地再响应，队列最多一个动作。
- 眨眼间隔不再固定重复；闭眼帧有短过渡。待机包含轻微呼吸、头部变化和头发余动。
- 姿势自动轮换改为约 60–85 秒，并避开输入、拖动、回复等待和正在播放的动作。跨姿势采用短暂淡化加缓慢稳定，减少旧版长时间双重人影。

**素材能力说明：**经典立绘使用局部网格动画；新的站姿使用可替换分层部件动画。仍没有完整的站起／坐下中间绘画帧，跨姿态转换仍是过渡效果，不是真正 Cubism Live2D。

## 右键菜单

| 功能 | 使用方式 |
|---|---|
| 安静陪伴 | 减少动作幅度，暂停自主小动作与自动换姿势，最高 30 帧；仍能点击和聊天 |
| 小睡／唤醒 | 闭眼趴下，轻缓呼吸；单击或发送消息唤醒，恢复此前手动姿态或自动陪伴 |
| 锁定桌宠位置 | 防止拖动误移；点击互动、滚轮缩放仍可用 |
| 显示聊天输入栏 | 可独立隐藏，右键角色或托盘菜单恢复 |
| 显示左侧数据栏 | 可独立隐藏，余额查询继续运行 |
| 动画帧率 | 30 帧节能、60 帧均衡、120 帧高刷新；记住选择 |
| 鲸鱼娘的姿态 | 站着、坐着、趴着或随性换姿势 |
| 角色模型 | 内置分层模型、经典立绘或其他本地 `model.json` |
| 字号与缩放 | 字号 13–18；角色滚轮缩放 40%–220%，气泡上 Ctrl+滚轮也可 |

帧率是绘制目标上限，实际受显示器刷新率、WPF 合成、显卡和负载影响。60 Hz 屏幕不会显示 120 个独立画面。修正了以“上一帧时间”限速造成的额外丢帧，按时间推进动作，30／60／120 帧下动作持续时间一致。隐藏窗口不更新角色网格，小睡和安静模式自动降低更新频率。

## 对话与扣费

在脚下输入，Enter 或箭头发送。文字出现在角色上方的回复气泡，带“你刚刚说的话”和逐字回复。“全文”立即显示完整内容，长回复可滚动、复制，× 收起，右键可恢复上次回复。API 对话需要有效密钥并会产生费用；本机摸头、连击台词不请求聊天 API。聊天上下文保留本次运行最近六轮，不写聊天日志。

每次成功查到余额减少，头顶浮出 **−0.01** 一类带描边数字，逐渐上移淡出，同时做轻微回应。睡觉、安静模式和隐藏输入栏均保留后台查询与浮字。浮字不占回复气泡，最多四条。人民币显示减少额，其他币种附货币代码。首次查询、充值和余额未变不会误报；这表示两次查询之间的余额差，不是逐笔账单。

默认每 60 秒刷新余额，设置可改 30–300 秒。菜单仍保留余额组成、近七天观测记录、低余额／预算预警、API Key 设置、隐藏、退出。隐藏整个桌宠后从系统托盘恢复。

## 参考的软件

- [VPet](https://github.com/LorisYounger/VPet)：参考其摸头等多种互动，以及独立说话栏和动作组织方式；本版加入头部点击反馈与休息状态。
- [BongoCat](https://github.com/ayangweb/BongoCat)：参考操作与角色回应相呼应的体验，改进连击响应时机与鼠标附近的轻微关注。本版只处理自身窗口内的交互，不采集其他应用的输入。

以上是功能与体验参考，未复制它们的角色素材或程序代码。

角色以 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 的形象为参考重绘。原有与新增的分层素材生成提示词随仓库保存，不把参考角色设计宣称为完全独立原创，也不将参考仓库的代码许可延伸到美术素材。

## 数据与检查

API Key 使用 Windows DPAPI 加密保存在当前用户目录，未勾选记住则不落盘。设置与余额观测位于 `%LOCALAPPDATA%\DeepSeekWhaleStandalone\settings.json`。请勿同时运行两个版本，以免它们重复查询或覆盖同一设置。

本轮已通过离线检查：2880 组动作取样、分层模型加载与路径校验、网格翻折与地面接触检查、30／120 帧平滑一致性、透明渲染、点击层级、休眠恢复、安静模式、扣费浮字回收，以及 24 组缩放／字号／输入栏布局。没有使用真实密钥发起付费聊天。动态预览 GIF 为 30 帧演示，不代表实际桌面刷新率。

源码在 GitHub 仓库中提供。下载便携 ZIP 即可运行；开发者可下载仓库源码并运行根目录的 `build.ps1`，仅使用 Windows 自带的 .NET Framework 编译器。当前程序结合实时网格和分层贴图，发布包已移除未使用的历史 GIF 素材。
